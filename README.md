# PHP Assignments – Elzero Web School

This repository contains my solutions and practice exercises for **PHP** from  
**Elzero Web School**, organized in a clean and scalable structure.

The main goal of this repository is to build a strong foundation in PHP that will
later be used for **WordPress Theme & Plugin Development**.

---

## 📚 Repository Structure

.
├── basics # PHP basics (syntax, variables, data types)
├── arrays # Arrays and array functions
├── conditions # If, else, switch statements
├── loops # For, while, foreach loops
├── functions # Functions and parameters
├── oop # Object-Oriented Programming (OOP)
├── projects # Small practice projects
└── README.md 


Each topic is divided into lessons, and each lesson contains:
- `index.php` → PHP code and solutions
- `notes.md` → Personal notes (when needed)

## 🚀 How to Run the Code Locally

1. Install a local server (XAMPP, Laragon, or MAMP)
2. Move the project folder to the server root:
   - `htdocs` (XAMPP)
   - `www` (Laragon)
3. Navigate to any lesson and run the `index.php` file
